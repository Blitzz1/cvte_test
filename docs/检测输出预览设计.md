# 检测输出预览设计

> 2026-10-28。先明确实现边界，再实施。取代服务器原流HLS作为默认主预览；原HLS仅保留显式对照入口。

主视频必须从WIC EndDraw成功且锁定实际像素之后，截取本路真实输出格子。只有实际完成绘制的帧才能进入预览，接收后丢帧／呈现丢帧不能绕过该位置。HTTP按需提供JPEG快照，携带源帧ID、播放代次、实际绘制单调时刻、尺寸和快照序号；不重新拉流或解码。浏览器显示最新画面并提示距离实际输出的新鲜度，100%呈现丢弃时应保持最后画面且显示无新输出，停止／重连清除旧代次预览。

每路只保留一份最新WIC格子像素与对应JPEG，按请求续租、最多10次／秒捕获；没有预览请求时不复制或编码。JPEG编码在HTTP工作线程进行，不在主呈现线程编码；主呈现计时在预览复制前完成，但新增负载仍须实测。宫格复用同一逐路快照接口，关闭后中止请求，租约2秒后停止捕获。快照尺寸是实际软件输出格子，并非原始1080p画面的另一次全分辨率播放。

音频不另拉原流：使用已有“监听本路检测音频”接口，在本机实际WASAPI输出上选择对应路，另提供静音。浏览器JPEG画面有轮询／编码／显示延迟，不能以其与本机声音的肉眼差异替代WIC／WASAPI同步指标；此版本不声称浏览器内已实现同步音视频重封装。预览关闭或切换时停止该预览的音频监听，原流对照音频默认静音避免叠音。

服务器HLS改为按需生成。页面以“检测输出预览”和“原流对照”明确区分，正常点击打开走检测输出，只有显式点击对照才建立HLS第二拉流。pull_url省略时严格等于本路publish_url；配置示例显式写出地址，UDP默认仍经8555中继。

验证应包含：WIC实际画面可取且带真实帧身份、RTSP TCP呈现100%丢弃后快照不更新而解码仍推进、恢复后更新、停止／重启不显示旧画面、宫格与关闭租约、无音轨、原流对照隔离及资源上限。自动测试设硬截止并清理本轮进程；测试结果另行回填，设计不代表已通过。
