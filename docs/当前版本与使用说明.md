# 当前版本与使用说明

> 更新：2026-10-28；2026-10-28解码归因修正版。当前进度与待办唯一汇总见[最终交付核对](./最终交付核对.md)，历史报告保留其原版本与实验条件。

## 1. 启动和结束

在项目根目录PowerShell执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/check-runtime.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -Seconds 300
```

浏览器访问http://127.0.0.1:8080/，等待15～30秒；页面必须通过后台地址访问，不能直接打开index.html。上述入口5分钟自动关闭本轮检测程序和媒体服务；省略Seconds会持续运行，关闭网页不会停止后台。提前结束：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/stop.ps1
```

依赖提前缓存，启动不下载。办公本优先单路预览，测试设时限、资源保护和清理；本轮文档核对不启动媒体程序或长测。

## 2. 素材与本机配置

仓库默认模板为四条独立完整链路：RTSP UDP、RTSP TCP及两条RTMP；sample-3m.mp4为合成H.264／AAC、1080p30、48kHz音频，不带检测标记。Sintel为普通1080p24含B帧素材；sample-1080p30-no-audio.mp4为1080p30真正视频单轨。各路可复用或更换文件，标识、地址、生命周期和检测仍独立。

**当前用户工作副本已修改config/app.json：第1路换为无音频素材，revision为8；这些用户修改保留，不混入文档提交。**该链路未显式填写has_audio:false；使用视频单轨应补该字段并重启对应路，不能称当前工作副本满足“四路均含音频”的长测负载。revision随网页保存变化，不作为固定版本要求。

manual-start.json可先0路再逐路启动；no-audio.json已正确声明第1路无音频；ordinary-material.json使用普通24fps；stability-four.json固定四路1080p30含音频，专用于长测。音频声明、替换、保存与重启规则见[素材替换与逐路操作](./素材替换与逐路操作.md)。

## 3. 当前预览、音频与地址

主预览及宫格复用同路WIC完成输出后的像素：WIC像素→JPEG图片编码→HTTP获取→浏览器替换图片，按需最多10次／秒。它不是30FPS连续视频，四路格子通常500×300；检测输入仍完整解码1080p30，检测输出帧率看实时指标，不能把预览取样算作检测丢帧。呈现停止时保留最后实际画面，停止／重连清除旧画面。

音频通过“监听检测音频（本机）”选择实际WASAPI输出；浏览器JPEG另有显示延迟，不能用肉眼与本机声音的偏差替代主同步指标。浏览器内同步音视频传输未实现。只有显式“原流对照”才从服务器额外拉HLS，默认静音，服务器按需生成HLS；关闭主预览后最多2秒租约过期即停止快照捕获。

pull_url省略则取本路publish_url；显式写入后两者独立，改publish_url不自动覆盖pull_url。UDP路推送8554/chain1，经8555/chain1拉取；8555为C++程序内的本机RTSP／UDP中继，转发到MediaMTX8554，观察RTP并按配置注入真实视频数据报丢弃。不是另一个MediaMTX，也不重新编码。其余各路直连各自服务器路径。细节和实测见[检测输出预览验收记录](./检测输出预览验收记录.md)。

## 4. 测量及归因边界

主延迟为同机文件源实时释放到WIC软件像素完成，不包含原素材制作时采集编码、物理屏幕发光或浏览器展示。音画偏差正值表示音频超前，基于源媒体共同时间轴和WASAPI消费位置，源素材自身同步是前提。

接收后丢帧在解码前随机丢完整压缩单元，可能额外影响依赖帧解码；呈现丢帧在解码后，不破坏解码参考。随机30%不是固定每100帧丢30帧，更不是最终未呈现率30%。默认统计源帧年龄5～15秒的10秒成熟窗口，故障切换后需等待旧窗口滑出。

当前按成功提交后的独立等待时间和同代次证据，将无输出细分为解码未产出、输入缺失后解码未产出、传输损伤后解码未产出；输入缺失关联不等于证明具体参考依赖。未关联输出或证据不足仍保留unknown_missing及上下界。R-01限时RTMP／RTSP回归与原始审计通过，见[解码修复记录](./解码未产出归因修复记录.md)。
