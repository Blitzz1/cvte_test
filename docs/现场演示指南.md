# 现场演示指南

> 2026-10-29，按当前程序和单链路页面整理。本文是现场操作顺序，尚未执行的原生浏览器／断网演练不写作已通过；当前用户暂停功能改动和后续推进。

## 1. 准备与限时启动

接电源、关闭无关重负载，保留本机third_party、runtime、web/vendor和data/media，不临场下载或升级依赖。Chrome主演示，Edge兼容需实际核对。先确认本项目旧实例已停止，再执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/check-runtime.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -Seconds 300
```

统一入口默认single-chain.json，恢复其保存后的页面集合；首次模板单路，新增页面可逐路扩大。标准4路1080p30含音频演示可明确使用 `-Config config/stability-four.json`，不要把日常无音频配置当成正式负载。manual-start预定义四页但不自动运行；ordinary-material为24fps，no-audio首路无音轨，详见[使用说明](./当前版本与使用说明.md)。

访问http://127.0.0.1:8080/，等待15～30秒预热。端口8080看板、8554 RTSP、8555本机UDP中继、1935 RTMP、8888按需HLS及9997服务器本机API；冲突先看日志，不误停无关进程。5分钟是本示例硬截止，现场需要更长时显式指定Seconds并负责收尾。

## 2. 整体链路与正常展示

1. 说明一条完整链路=一份文件按实时释放→推流→MediaMTX→拉流解码→WIC／WASAPI；4推＋4拉计4路，素材可同可不同。
2. 查看当前页卡片、三张图、输入／输出帧率和有效性；通过标签切换检查其他路仍在运行。需要逐路增加时用新增页面选择协议和音频声明。
3. 打开检测画面，解释它是同路WIC像素的最多10Hz镜像；主检测仍按源帧运行。原流对照才额外拉HLS，默认静音；本机监听与网页图像有额外相对显示延迟。
4. 查看观测与归因，区分卡片传输段和完整端到端；RTSP当前约一帧组帧等待不是协议固定延迟。音画正值声音超前，未标记素材自身同步为前提。
5. 选择1／6／24小时及自定义历史，只展示已保存数据。停止和重启不清数据库，关闭页面后可按旧ID查询历史API。

## 3. 三类异常与恢复

每次仅作用于选中一路，确认其他路持续输出；清除故障后等待输出队列、告警恢复和成熟窗口滑出，不要求瞬间清零。操作前保留正常对照，按真实观测解释，不调高阈值遮掩异常。

| 操作 | 应讲解的实际变化 |
|---|---|
| 视频延后800ms | 卡片传输基本不变；解码后呈现及完整端到端增加约800ms，音频相对超前；完整端到端告警仍可能触发 |
| 音频延后350ms | 偏差向负方向约350ms；视频端到端基本不变 |
| 呈现丢弃20%／100% | 呈现结局及输出帧率变化；100%时WIC无新帧、镜像冻结，原流对照可继续播放 |
| 接收后丢帧30% | 完整压缩输入被真实丢弃，可能进一步导致其他帧解码未产出；最终损失不必等于30% |
| RTSP UDP丢包2% | 仅经8555中继路径适用；RTP包缺口、帧损伤及最终呈现分别解释，不将包率直接换算帧率 |

TCP／RTMP不提供任意删网络字节注入或底层TCP重传统计，但支持接收后／呈现丢弃及延后。归因依源收账本和实际事件，具体参考依赖未证明时保留限制。无音轨同步应为空且不适用，不能展示0ms正常。

## 4. 页面生命周期、配置与通知

“停止”保留页签，“关闭页面”停止并持久移除页签，历史保留；最后一页可关闭、空工作区可新增。关闭页面会更改本次启动配置，演示前需要复现初始页面集合时先备份自己的配置，不临场覆盖用户文件。

运行配置JSON保存阈值立即生效，素材／地址修改需重启对应路，保留revision。Webhook可配置为http://127.0.0.1:8080/webhook-demo，按同event_id核对告警、发送和接收；HTTP最多3次尝试，HTTPS及重启恢复未发送队列不在已实现范围。

## 5. 结束、离线与答辩

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/stop.ps1
```

结束后确认检测和MediaMTX均退出；关闭浏览器不算收尾。指标、事件、旁路事实及素材保留，默认不录完整接收媒体。

如后续恢复离线验收，由现场用户配合断开外网并保留本机回环，核对检查、统一启动、预览、三类异常／恢复及历史，再清理。该物理断网步骤目前未执行，不能只凭依赖存在判通过。

答辩使用[设计文档](./设计文档.md)架构及T0／T1／T2a／T2b／T3／T4口径：源释放非原采集，完整帧返回非网卡到达，WIC非物理发光，设备消费非声学到达，JPEG非同步浏览器媒体。冻结按新帧间隔，丢帧按源视频结局，底层TCP丢包与最终帧缺失不同。

旧四路一小时达到其运行／资源判据但有短冻结、呈现丢弃和未知；八路一小时失败；最新版本未重跑一小时。所有待签收及加分限制统一见[需求追踪](./需求追踪与验收状态.md)，不以当前界面可见代替测量／稳定性证据。
