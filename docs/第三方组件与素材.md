# 第三方组件与素材

源码不包含检测内容标记。项目使用的第三方原始归档、头文件及构建产物放在本机 `third_party/`，版本与SHA-256见 `config/dependencies.lock.json`；演示前缓存完成，运行时无需联网。

- 下载来源：`https://download.blender.org/durian/trailer/sintel_trailer-1080p.mp4`。
- 本机位置：`data/media/sintel-trailer.mp4`，不放入Git。
- SHA-256：`34bbd52a4b89fdf63c8ace50b268da26653a59508288100cd3c23de276db7931`。
- 原始H.264／AAC，1920×1080，24fps，含B帧，约52.208秒。保留原素材，不叠字、不植入声音或SEI；循环时只连续推进传输时间戳。

`scripts/make-sample.ps1`生成的1080p30合成图形／正弦音测试流仅用于可控负载与故障验证；默认已恢复1080p30合成演示素材sample-3m.mp4，普通电影素材保留为显式配置；stability-four.json固定30fps负载验收。输入自身同步为项目检测前提，未进行内容语义口型分析。

## 视频单轨测试素材

已准备data/media/sample-1080p30-no-audio.mp4，由sample-3m.mp4复制视频压缩流并移除音轨，不重编码、不覆盖源文件。ffprobe确认H.264、1920×1080、30fps且没有音频流。用no-audio.json测试或设置has_audio=false；生成脚本为scripts/prepare-no-audio.ps1。当前三份素材哈希见evidence/2026-10-28/udp-loop-fix/fixtures.json。
