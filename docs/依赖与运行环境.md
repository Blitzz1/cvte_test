# 依赖与运行环境

## 开发工具（已验证）

- Visual Studio Community 2026安装目录：`C:\Program Files\Microsoft Visual Studio\18\Community`。
- 使用MSVC 14.44（编译器19.44.35229）x64，Windows SDK 10.0.26100。
- 使用VS附带CMake 4.3.1-msvc1、Ninja，通过`vcvars64.bat -vcvars_ver=14.44`初始化单次进程环境；不依赖当前应用PATH是否刷新。
- Git 2.56.0.windows.3，作者仅在项目配置；每阶段提交使用简短中文说明。

## 依赖准备

`powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/prepare-deps.ps1`只在首次准备阶段联网，不更改全局执行策略。下载内容位于忽略的`third_party/`，具体文件及SHA-256写入`config/dependencies.lock.json`。已有锁文件时必须匹配哈希，刷新需显式`-Refresh`并审查变更。

MediaMTX固定v1.21.3，包哈希与官方发行页核对。FFmpeg选择8.1分支共享发行快照，下载后记录实际版本、构建选项及哈希；地址名称可滚动，不等于允许以后自动替换已锁包。保留原始归档以供离线复现。FFmpeg发行包由BtbN构建，属于第三方二进制，需要记录GPL构建、源代码来源与许可证；不得宣称整个打包产物为无条件宽松许可。

候选小依赖：nlohmann/json 3.12.0、cpp-httplib 0.28.0、hls.js 1.6.13、SQLite 3.50.4。运行资源本地化，不使用CDN。下载脚本本身不证明库已编译或互通。

## 实施调整

核心单元测试先使用独立CTest可执行目标及清晰断言，减少首轮测试框架依赖；不影响核心逻辑必须有单测的要求。后续可按需要引入Catch2。当前尚未下载／使用spdlog；正式运行日志仍需实现可追溯与轮转，而不是把规划库名当功能完成。
