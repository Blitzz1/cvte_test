## 依赖准备

`powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/prepare-deps.ps1`只在首次准备阶段联网，不更改全局执行策略。下载内容位于忽略的`third_party/`，具体文件及SHA-256写入`config/dependencies.lock.json`。已有锁文件时必须匹配哈希，刷新需显式`-Refresh`并审查变更。

MediaMTX固定v1.21.3，包哈希与官方发行页核对。FFmpeg选择8.1分支共享发行快照，下载后记录实际版本、构建选项及哈希；地址名称可滚动，不等于允许以后自动替换已锁包。保留原始归档以供离线复现。FFmpeg发行包由BtbN构建，属于第三方二进制，需要记录GPL构建、源代码来源与许可证；不得宣称整个打包产物为无条件宽松许可。

已落地小依赖：nlohmann/json 3.12.0、cpp-httplib 0.28.0、hls.js 1.6.13、SQLite 3.50.4。运行资源本地化，不使用CDN。下载脚本本身不证明库已编译或互通。

## 运行与开发检查的区别

主程序演示使用已准备的Windows系统组件、FFmpeg DLL、MediaMTX、本地网页资源和素材；不要求Node／Python服务。Node执行tests/*.cjs、Python执行scripts/audit-*.py，是开发／审计工具。离线重建还需已安装的编译器、SDK、CMake／Ninja及本机依赖文件；仅克隆Git源码不包含被忽略的大依赖和素材。

构建入口scripts/build.ps1调用vcvars64初始化当前进程，然后使用仓库CMake预设。完整构建的CTest位于build，未将ctest加入PATH时本机可用路径为：

```powershell
& 'C:/Program Files/Microsoft Visual Studio/18/Community/Common7/IDE/CommonExtensions/Microsoft/CMake/CMake/bin/ctest.exe' --test-dir build --output-on-failure
```

scripts/check-runtime.ps1仅核对本地运行材料，不代表物理断网演练已通过。Git若提示目录所有者不同，可针对用户确认的本项目绝对路径设置safe.directory，勿使用全局通配信任；提交作者按本项目既有配置，每次提交简短说明。
