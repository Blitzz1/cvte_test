# 检测输出预览验收记录

> 2026-10-28，北京时间。实现与限时回归已完成；不代表本版本重新完成一小时稳定性或浏览器内同步音视频编码传输。

## 实现结果

默认“打开检测画面”及宫格均复用本C++程序已完成的WIC输出，不重新从MediaMTX拉媒体流。WIC绘制成功、锁定软件像素并记录实际呈现后，按格复制本路输出；HTTP工作线程用Windows WIC编码JPEG，画面响应带帧身份、代次、真实呈现时间和快照序号。主测量仍在预览复制前记录，原始检测公式未改。

预览是最多10张／秒、实际软件输出格子分辨率的展示镜像；四路布局通常为500×300，本来就经过主软件输出缩放，不冒充1080p原生预览或30fps浏览器播放。10Hz展示取样不用于计算丢帧。每路保留最新画面和编码缓存，没有逐帧积压；无请求2秒后停止捕获，冻结时复用最后实际画面，停止或重连清除旧批次。浏览器关闭／切换会中止轮询、释放对象URL；原流HLS只通过“原流对照”显式打开，服务器改为按需HLS。

音频使用现有本机WASAPI实际检测输出，点击“监听检测音频（本机）”选择路，静音或关闭预览可停止监听；没有另拉原流音频。JPEG到浏览器存在展示延迟，声音在本机设备直接输出，不能声称网页画面与本机声音无额外相对延迟，更不能以肉眼差异替代主同步指标。这版没有实现浏览器内同步音视频重封装。

## 拉流地址规则

pull_url是可选字段，省略时取**同一chain**的publish_url，并非所有链路共用第一路地址。当前配置示例已补显式地址，运行配置API也显示补全后的地址。若显式填写pull_url，则它独立生效；之后只改publish_url不会自动覆盖已有pull_url。

| 链路 | publish_url | pull_url |
|---|---|---|
| RTSP UDP | rtsp://127.0.0.1:8554/chain1 | rtsp://127.0.0.1:8555/chain1 |
| RTSP TCP | rtsp://127.0.0.1:8554/chain2 | rtsp://127.0.0.1:8554/chain2 |
| RTMP第3路 | rtmp://127.0.0.1:1935/chain3 | rtmp://127.0.0.1:1935/chain3 |
| RTMP第4路 | rtmp://127.0.0.1:1935/chain4 | rtmp://127.0.0.1:1935/chain4 |

第一路8555是本项目UDP检测中继，再向MediaMTX8554取流；其他路可直接访问服务器各自路径。原流预览的HLS地址是另一种显式对照，不是pull_url的默认值。

## 实验及证据

四路自动检查入口scripts/validate-preview.ps1，硬截止90秒、内存／CPU保护、异常finally收尾；实际约34.55秒结束，第1路视频单轨、其余路含音频，全部为1080p30合成素材。全量事实保留在artifacts/preview-20261028-163153及data/observations，精简证据在docs/evidence/2026-10-28/output-preview。

- 正常：实际JPEG可解码，带源帧身份及播放代次。scripts/audit-preview.py逐一核对93次JPEG响应，均找到身份／代次／呈现时间完全一致的software_present原始记录，不匹配0。
- RTSP TCP呈现丢弃100%：解码仍推进，实际输出0fps，成熟窗口已证实丢帧100%；64次冻结观测的快照序号没有前进。其余三路约30fps，无音频路同步为不适用。
- 恢复：快照重新前进；停止后返回204并清空旧画面，重启后取得新代次画面。
- 单路及多路快照接口均实际请求；全程HLS实例数0，未产生服务器额外HLS预览。
- 应用私有内存峰值114.04MiB、MediaMTX90.02MiB，归一化合计CPU采样峰值约5%，资源保护未触发。此为短测，不是长时内存趋势结论。
- CTest四项通过：detection_core、video_conversion、storage_persistence、output_preview；新增预览测试检查无租约不捕获、真实JPEG、10Hz限额、冻结缓存及代次清理。前端测试检查HTTP轮询、冻结提示、停止清图、重连及关闭请求。

随后用单路RTSP TCP的临时配置做内置浏览器检查，有240秒硬截止与资源保护。确认主画面500×300且原流video隐藏；在页面应用100%呈现丢弃，主画面冻结、显示约1406ms无新画面、实际输出0fps，恢复后更新，关闭后停止轮询。截图browser-normal.png、browser-frozen.png及browser-checks.json已保存；没有听测本机声音或打开原生Edge／Chrome。所有本轮应用和媒体服务器已确认退出。
