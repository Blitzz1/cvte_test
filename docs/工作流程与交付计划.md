# 工作流程与交付计划

> 2026-10-29修订。保留“先需求／可行性／设计，再对应代码，测试与文档同步”的规则；旧逐日实施快照由Git历史保留，不重复充当当前待办。前轮文档冻结后，本轮按用户反馈仅修复UDP归因；其余工作仍不自动推进。

## 1. 文档分工

| 文档 | 写作时点与职责 |
|---|---|
| 需求与验收基线 | 实现前确认范围；后续需求变更先更新，不把实际缺口改写成需求已取消 |
| 可行性分析报告 | 业务实现前初版，启动后2天内；明确库原始数据层级、关键风险、验证与选型；验证后更新成实际结论 |
| 设计文档 | 核心代码前初版，启动后3天内；模块、接口、并发、口径、窗口、证据与边界先明确，随代码同步 |
| 测试计划与记录 | 编码前写预期与证据需求；实现后填真实条件、版本、结果及失败；不以计划当通过 |
| README／当前使用说明 | 命令、配置与页面形成后立即补，用真实入口维护，不堆叠多轮“最新补充” |
| 需求追踪与验收状态 | 每个闭环更新实现／验证／限制，是当前状态和剩余验收唯一总账 |
| 专题实验记录／evidence | 每次重要修复保存方法、版本、原始摘要及局限；历史证据不重写 |
| 现场演示指南 | 集成后形成，最终用冻结版本核对，不把未演练步骤写成已通过 |

## 2. 已采用实施顺序

1. 明确完整链路、普通素材无标记、软件终点及源同步前提，保存需求和Git。
2. 初版可行性、依赖调查与关键能力实验；锁定工具链、原始字段与自研边界。
3. 核心设计、指标四项口径和测试判据完成后，建立CMake骨架与最小单路。
4. 实现源收关联、真实音视频观测、三类指标及独立故障注入，逐项验证并同步设计。
5. 扩展4条完整链路、生命周期、告警、存储、配置、看板和历史。
6. 实际问题驱动修复：资源与时钟、UDP大帧、WIC预览、解码未产出归因、动态新增关闭及细化计时；各专题分别保存证据。
7. 冻结版本后安排最终稳定性、原生浏览器、离线与现场演示，最后签收；目前此最终步骤尚未全部完成。

代码实现后才形成的事实不能倒填为最初已知；历史四路／八路长测按当时版本保留。原约定目标为2026-10-29北京时间14:00、最晚16:00，报告提交和实际完成时间以Git及实验记录为准，不伪造里程碑。

## 3. 后续恢复工作的标准闭环

当前不自动推进。若用户之后授权恢复，按以下顺序：

1. 检查工作区与当前配置，保护用户修改；明确本次目标是否仅验收或含代码。
2. 先更新受影响需求／设计、观测点与测试判据。若只是实现细节，按既定范围处理；涉及范围变化再确认。
3. 编写对应代码和必要核心测试，避免引入与目标无关的协议或依赖。
4. 运行相称的构建、单元／前端检查，必要时单路限时实流；事实审计不能用注入设定值当答案。
5. 同步接口、使用说明、需求追踪和实验报告，再提交一个目的明确的Git记录。
6. 影响资源、并发、测量或生命周期时重新评估最终长测覆盖，不能沿用旧版结果直接签收。

文档单独整理只检查链接、字段、命令和源码一致性，不为改Markdown启动媒体负载。

## 4. 保留的验收顺序

当前R-01已在已测范围关闭；R-02预览体验、R-03最终版4路一小时、R-04物理断网、R-05最终演示仍保留，定义只维护在[需求追踪](./需求追踪与验收状态.md)。恢复时先固定配置和版本，再按负载由低到高验证，最后签收，不先扩展高风险加分。

原生Chrome主演示、Edge兼容，需覆盖页面、真实检测镜像、音频范围、切换、历史、配置及关闭。离线演练不以“DLL存在”替代物理断网实测；一小时不以“进程存活”替代帧率、有效性、冻结、未知及资源审计。

## 5. 办公本与测试纪律

- 单路优先，只有必要时运行4路；不擅自重复8路长测。
- 每轮媒体自动测试写明硬截止、CPU／内存保护、独立临时配置和finally清理。
- 到期或异常结束检测和MediaMTX，核对PID、路径、创建时间，不能只停止采集器或误杀他人进程。
- 默认统一启动可使用-Seconds 300；一小时只在明确安排后显式运行，不用持续运行入口替代保护脚本。
- 原始事实、注入真值分离，证据丢记录数公开；无效／未知不显示正常数值。
- 启停和关闭页面保留数据库及素材；验收配置使用stability-four，不把日常无音频负载当4路含音频。

## 6. Git与交付规则

每次提交使用简短明确说明；相关代码、设计与验证可一起提交，不预建空提交、倒写时间或改写历史。提交前查看差异、运行适当检查，不混入用户配置、临时文件、依赖、完整数据库或秘密。

必交付包括独立可行性报告、设计、源码／CMake／运行材料、测试及证据、README和使用说明、需求追踪与现场演示指南。依赖和素材按许可及忽略策略另行本机保留；文档齐全和文件数量不是最终验收判据。当前整理完成后继续保持暂停状态。
