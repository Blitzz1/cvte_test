每页仅显示一条链路卡片、三张曲线、本路诊断／事件、检测输出和原流对照。顶部标签在链路之间切换，切页只关闭旧预览和音频监听，不停止后台检测。新增页面对话框可选RTSP TCP、RTSP UDP或RTMP，设置名称、源文件与音频声明；服务自动分配唯一ID／本机URL，持久保存并异步启动。最多8条注册链路；统一启动入口改用single-chain.json，首次一条链路，新增后保存并在下次恢复；原app.json保留，可显式指定。

宫格移除。检测JPEG与独立HLS可同时打开、分别关闭，窄屏上下排布、宽屏并排；保留10Hz镜像与本机音频展示延迟说明。希望从一路开始可用config/single-chain.json，之后新增；不要把关闭网页当作停止服务。

## 2. 真实测量口径

卡片／延迟曲线为transport_ms，直接用同帧源端释放→接收线程av_read_frame返回完整压缩包的真实单调时间差（哈希匹配前取值）。它包括推流、服务器、协议／解复用等待，不能冒称纯物理网络延迟。

接收后另记录送入解码调用前、成功返回、对应解码帧产出和WIC完成。decoder_ms包含send_packet内部可能发生的同步解码、后续取帧与重排序；submit_call_ms是其中子集，不重复相加。receiver_processing_ms是完整接收到呈现，原latency_ms仍是源端到WIC的完整端到端值，现有告警仍用该值。

传输值使用近1秒全部匹配接收样本；完整分段使用近1秒已呈现且六个真实边界均存在的同组样本，独立公开样本数。pipeline_transport_ms＋receiver_processing_ms＝pipeline_total_ms用于同组核对，不能将不同样本均值直接相减。缺失／过旧／没有源参考及旧历史无新字段时留空，不补猜测。
