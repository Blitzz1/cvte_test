# 素材替换与逐路操作

> 2026-10-28。默认恢复此前1080p30演示素材；普通24fps素材保留用于回归。所有命令均在项目根目录PowerShell执行。

## 已准备的素材

| 文件 | 视频 | 音频 | 用途 |
|---|---|---|---|
| `data/media/sample-3m.mp4` | H.264、1920×1080、30fps合成演示画面 | AAC、48kHz | 默认四路、标准30fps负载 |
| `data/media/sintel-trailer.mp4` | H.264、1920×1080、24fps、含B帧 | AAC、48kHz | 普通素材、B帧及循环回归，显式配置ordinary-material.json |
| `data/media/sample-1080p30-no-audio.mp4` | H.264、1920×1080、30fps | **没有音频流** | 真正视频单轨测试，不是静音音轨 |

视频单轨文件通过FFmpeg复制sample-3m的视频压缩流、去除音轨生成，原文件未改动，视频未重编码。文件均已在本机准备好；哈希见 `evidence/2026-10-28/udp-loop-fix/fixtures.json`。需另行生成时可运行 `scripts/prepare-no-audio.ps1 -Source 输入文件 -Output 新输出文件`，脚本不覆盖已有文件。

`config/no-audio.json`：第1路使用视频单轨且has_audio=false，其余三路使用含音频的30fps素材。启动：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -Config config/no-audio.json -Seconds 300
```

无音频链路仍检测视频延迟、丢帧和冻结；音频及同步为not_applicable，偏差为空，不显示0ms“正常”。使用前先停止已有实例，不能同时启动多个配置占用相同端口。

## 在网页自行替换素材

1. 将文件放进 `data/media/`，例如 `data/media/my-video.mp4`。本机已验证的格式是H.264／AAC；其他编码不能仅凭扩展名断定兼容。
2. 打开看板左侧“运行配置”，找到对应链路的source字段，改成文件路径。每一路可以不同。
3. 含音频文件设置has_audio=true（未写时默认true）；视频单轨设置has_audio=false。当前页面没有独立音频开关，需要在下方JSON中找到对应chains对象，手动补上该字段；所以原配置中可能看不到现成的has_audio一行。
4. 点击保存，再回到总览选择相应卡片，点击“重启”。仅修改素材路径不会自动切换正在运行的链路；其他路无需重启。

字段示例（这是片段，修改现有链路中的字段，不要用片段替换整个配置）：

```json
"source": "data/media/my-video.mp4",
"has_audio": true
```

也可使用绝对路径，如 `D:/videos/demo.mp4`；建议使用正斜杠，避免JSON反斜杠转义问题。网页保存的是本次启动使用的配置文件，默认是config/app.json。保留网页读出的revision，不自行重置；版本冲突时重新加载后再修改。当前网页为JSON编辑器，没有浏览器本地文件上传按钮。

直接用编辑器修改配置文件也可以，但运行中后台不会自动重新读取磁盘改动；**直接改文件后需要停止并重新启动应用**。运行中推荐通过网页保存再重启对应路。

## 先启动一路，再增加其他路

使用已准备的手动启动配置（四条都在列表中，启动时均停止）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -Config config/manual-start.json -Seconds 300
```

进入总览，点击某张卡片，再点详情中的“启动”；该路有输出后，依次选择其他卡片并“启动”。可同时运行1～4路。

运行中关闭某一路：选择那一路，点击“停止”；其他路继续检测。重新点击“启动”即可恢复。点击预览的“关闭”只关闭额外预览，**不是停止检测流**。

配置enabled字段表示应用启动时是否自动启动该路，不是运行中的实时开关；实际启停使用详情按钮。运行时的停止状态不会自动修改enabled，所以下次启动仍按配置决定。已验证“先1路→增加3路→停1路→恢复”，其余路会话保持不变，证据见UDP修复记录。

结束执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/stop.ps1
```

关闭网页不会结束后台；上述示例都有5分钟自动截止。素材替换和启停不会清空数据库，历史查询仍能看到同一链路此前的记录；更换素材后请按本次运行时间查看，避免混淆不同测试条件。
